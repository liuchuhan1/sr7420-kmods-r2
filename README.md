# SR7420 r2 kmod 软件源

本仓库提供 SR7420 **r2** USB 系统对应的 1109 个 kmod APK、1 个 kernel APK 和签名索引。

- 架构：`aarch64_cortex-a53`。
- 完整 kernel ABI：`6.18.60~2b497291254683b6ce56b38338fafb7e-r1`。
- 索引：`aarch64_cortex-a53/6.18.60~2b497291254683b6ce56b38338fafb7e-r1/packages.adb`。
- 软件源配置：`repositories/sr7420-r2.list`，包含可直接使用的完整 HTTPS 地址。
- 公钥：`keys/public-key.pem`。公钥与配套镜像内置公钥一致；仓库不包含私钥。
- 1109 个已选模块包全部编译；403 个未选中项及功能说明见 [KMODS.md](KMODS.md)。

`r2` 表示本项目的系统/仓库代际；内核包自身的版本后缀仍为 `-r1`，不能将其手工改为 `-r2`。软件包只适用于上述完整 ABI，不应强制忽略内核依赖。

## 校验范围

每个 APK 的大小和 SHA256 记录在同目录 `manifest.json`。所有软件包与索引已在构建机上校验签名，两个版本的索引还通过了真实路由器的 apk 签名检查。发布文件与导出的构建产物逐一做了哈希核对。报告在 `reports/`。

这不表示所有驱动都与 SR7420 的硬件有关，也不表示每个包/安装组合都做过硬件测试。

## 版本保留

r1 仓库 `sr7420-kmods` 保留原软件包和签名索引，只修正了文档中的错误路径。r1 与 r2 分开提供，不混用两版内核 ABI。

本版 apk 请求 `packages.adb`；`package.db` 不是本软件源需要发布的索引文件名。
